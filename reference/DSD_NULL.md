# Placeholder for a DSD Stream

Placeholder for a
[DSD](https://michael.hahsler.net/stream/reference/DSD.md). `DSD_NULL`
does not produce points and creates an error for
[`get_points()`](https://michael.hahsler.net/stream/reference/get_points.md).

## Usage

``` r
DSD_NULL()
```

## Value

Returns a `DSD_NULL` object (subclass of
[DSD](https://michael.hahsler.net/stream/reference/DSD.md)).
