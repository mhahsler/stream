# Deprecated DSD_ScaleStream

Deprecated! Use
[DSF_Scale](https://michael.hahsler.net/stream/reference/DSF_Scale.md)
instead.

## Usage

``` r
DSD_ScaleStream(...)
```

## Arguments

- ...:

  arguments are passed on to
  [`DSF_Scale()`](https://michael.hahsler.net/stream/reference/DSF_Scale.md).

## Value

Produces a warning that `DSD_ScaleStream` is deprecated and returns an
object of class
[DSF_Scale](https://michael.hahsler.net/stream/reference/DSF_Scale.md)
(subclass of [DSF](https://michael.hahsler.net/stream/reference/DSF.md)
and [DSD](https://michael.hahsler.net/stream/reference/DSD.md)).
