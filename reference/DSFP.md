# Abstract Class for Frequent Pattern Mining Algorithms for Data Streams

Abstract class for frequent pattern mining algorithms for data streams.
Currently, stream does not implement frequent pattern mining algorithms.

## Usage

``` r
DSFP(...)
```

## Arguments

- ...:

  Further arguments.
